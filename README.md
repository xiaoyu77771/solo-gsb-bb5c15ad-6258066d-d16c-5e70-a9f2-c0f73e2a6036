# 陶艺装窑预检 Web 应用（Kiln Pre-check）

在升温烧制前，于浏览器内对矩形窑室中的矩形坯体进行**热膨胀碰撞预检**：

- 设置矩形窑室尺寸、起始/目标温度；
- 添加可旋转的矩形坯体，赋予各自的**线膨胀系数** α_L；
- 画布上**拖放移动**、**手柄/滑杆旋转**摆位；
- 系统按线性温升 `s(T) = 1 + α_L·(T − T₀)` 放大坯体外廓；
- 采用**旋转矩形分离轴定理（SAT）**检测坯体之间、坯体与四壁的接触；
- 求出**目标温度内的最早接触温度**，高亮涉事坯体/窑壁并标注接触点；
- 修改任意参数**立即重算**，停止编辑 0.6 秒后**自动持久化**到本地 `data/plan.json`。

技术栈：Node.js + Express（后端/持久化 API）+ 原生 HTML Canvas（前端渲染交互），零前端构建。

---

## 一条命令启动（Docker Compose）

```bash
docker compose up --build
```

然后浏览器访问：

> **http://localhost:3000**

依赖安装（`npm install`）已包含在镜像构建阶段；容器启动时服务自动初始化——
若 `data/plan.json` 不存在，会自动写入一份内置示例方案。
方案文件通过 `./data` 目录卷映射持久化，重建容器不丢失。

停止：`Ctrl+C`（后台运行则用 `docker compose down`）。

## 不用 Docker 的本地启动

要求 Node.js ≥ 18。

```bash
npm install
npm start
```

访问 **http://localhost:3000**（端口可用环境变量 `PORT` 覆盖）。

## 操作说明

| 操作 | 方式 |
| --- | --- |
| 选中坯体 | 鼠标左键点击坯体，或点击左侧「坯体列表」 |
| 移动坯体 | 左键按住坯体拖动画布（支持触屏 Pointer 事件） |
| 旋转坯体 | 选中后拖动坯体上方圆形手柄；或使用属性面板角度滑杆；或键盘 ←/→（Shift 微调 1°，否则 15°） |
| 删除坯体 | 属性面板「删除坯体」按钮，或 `Delete` / `Backspace` |
| 添加坯体 | 左侧填写宽、高、α_L、初始角度后「＋ 放入窑室中央」，再拖到目标位置 |
| 保存 | 停止编辑 0.6 秒自动保存；也可点「保存方案」立即保存 |
| 恢复示例 | 点「恢复示例」重置服务端方案 |

画布中：

- 绿色填充矩形 = 坯体在**起始温度**下的外廓；
- 金色虚线矩形 = 坯体在**目标温度**下膨胀后的外廓；
- 红色填充/描边 = 最早接触时刻的**涉事坯体外廓**，红色加粗墙线 = 涉事窑壁；
- 红星标记最早接触点，下方表格列出目标温度内的全部接触，按温度排序；
- 点击表格行可在画布上定位该接触点。

## 线膨胀系数输入约定

界面中 α_L 的单位为 **×10⁻⁶ /°C**（陶瓷行业常用写法）。例如输入 `8` 表示
`8 × 10⁻⁶ /°C`（常见陶瓷坯体约 4 ~ 10 ×10⁻⁶/°C，具体请以泥料检测数据为准）。

## 计算原理

设起始温度 `T₀`、目标温度 `T₁`，归一化温升参数 `t ∈ [0,1]`，`T(t)=T₀+t(T₁−T₀)`。

坯体中心位置与旋转角不随温度改变，宽/高等比放大：

```
w(T) = w₀ · (1 + α_L · (T − T₀))
```

**坯体—坯体（旋转矩形 SAT）**：取两矩形各自的两条轴向作为候选分离轴。
矩形在轴 `n` 上的投影半宽为 `r = hw·|nₓ| + hh·|nᵧ|`，随温升线性变化。
对每条轴计算初始分离量 `sep₀` 与全温程闭合速率，闭合时刻 `tAxis = sep₀ / rate`；
两矩形接触要求所有轴同时闭合，故最早接触时刻取**所有分离轴闭合时刻的最大值**
`max(tAxis)`（解析求解，无迭代）。

**坯体—窑壁**：四壁为轴对齐直线，向 x/y 法向直接投影，同样解析求解间隙闭合时刻。

若 `t = 0` 即检测到侵入，标记为「起始已接触/越界」，提示先调整摆位；
`max(tAxis) > 1` 表示目标温度内不会接触。

## HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/plan` | 读取当前方案 JSON |
| `PUT` | `/api/plan` | 保存方案（写入 `data/plan.json`，原子替换） |
| `POST` | `/api/plan/reset` | 重置为内置示例方案 |
| `GET` | `/api/health` | 健康检查 |

方案 JSON 结构：

```json
{
  "name": "示例装窑方案",
  "tempStart": 20,
  "tempTarget": 1250,
  "kiln": { "width": 80, "depth": 60 },
  "bodies": [
    { "id": "b1", "name": "碗坯 A", "w": 16, "h": 16,
      "cx": 22, "cy": 20, "angle": 0, "alpha": 8 }
  ]
}
```

长度单位 cm，温度 °C，`angle` 为度数，`alpha` 为 ×10⁻⁶/°C。
